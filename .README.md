## Курсовой проект-2,3: "Трекер самолётов"

**Описание проекта:**
В этом проекте вам предстоит написать интеграцию с внешним сервисом.
Интеграция с внешним сервисом — это довольно распространенная задача для Python-разработчиков, которую можно встретить на платформах с фриланс-проектами.
В этой работе вам нужно будет реализовать программу,
которая будет собирать данные о самолетах в воздушных пространствах тех стран, которые вы выберете.
Чтобы получить географические координаты стран, будем использовать API nominatim.openstreetmap.org,
а чтобы получить информацию о самолетах — API opensky-network.org.

**Задачи проекта 1:**

**Шаг 1: создание абстрактного класса для работы с API**
Создать абстрактный класс для работы с API сервисов nominatim.openstreetmap.org и opensky-network.org.
Реализовать класс, наследующийся от абстрактного класса, для работы с платформами nominatim.openstreetmap.org и opensky-network.org.
Класс должен уметь подключаться к API и получать географические координаты стран и информацию о самолетах, находящихся в воздушном пространстве этих стран.


**Шаг 2: создание класса для работы с информацией о самолетах**
Создать класс для работы с информацией о самолетах.
В этом классе самостоятельно определить атрибуты: страна регистрации, позывной, скорость полета, высота полета и так далее (всего не менее четырех атрибутов).
Пример ответа с подробным объяснением значения каждого атрибута можно посмотреть тут: opensky-network.response.json.
Класс должен поддерживать методы сравнения самолетов между собой по скорости и высоте, валидировать данные,
которыми инициализируются его атрибуты. 

**Шаг 3: Создание классов для работы с файлами**
Определить абстрактный класс, который обязывает реализовать методы для добавления информации о самолете в файл, получения данных из файла по указанным критериям и удаления информации о самолетах.
Создать класс для сохранения информации о самолетах в JSON-файл. Дополнительно, по желанию, можно реализовать классы для работы с другими форматами: CSV- или Excel-файлом, с TXT-файлом.
Данный класс выступит в роли основы для коннектора, заменяя который (класс-коннектор), можно использовать в качестве хранилища одну из баз данных или удаленное хранилище со своей специфической системой обращений.
В случае если какие-то из методов выглядят не используемыми для работы с файлами, то не стоит их удалять. Они пригодятся для интеграции к БД. Сделайте заглушку в коде.

**Шаг 4: создание функции для взаимодействия с пользователем**
Создать функцию для взаимодействия с пользователем. Функция должна взаимодействовать с пользователем через консоль.
Возможности этой функции должны быть следующими:
Ввести название страны для запроса информации о самолетах из opensky-network.org.
Получить топ N самолетов по высоте полета (N запрашивать у пользователя).
Получить самолеты по стране их регистрации.
Помимо этого функционала, можно придумать дополнительные возможности, которые покажутся удобными.

**Шаг 5: объединение компонентов**
Объединить все классы и функции в единую программу.
Покрыть описанный функционал тестами.
Требования к реализации в парадигме ООП
Абстрактный класс и классы для работы с API должны быть реализованы в соответствии с принципом наследования.
Класс для работы с самолетами должен быть реализован в соответствии с принципом инкапсуляции и поддерживать методы сравнения самолетов между собой по скорости и высоте полета.
Классы и другие сущности в проекте должны удовлетворять минимум первым двум требованиям принципов SOLID.

**Следующий шаг проекта 2:**
* Получите данные о географических координатах стран с помощью https://nominatim.openstreetmap.org/ и о самолетах в воздушных пространствах этих стран
с сайта https://opensky-network.org/. Используйте публичный API https://opensky-network.org/ и библиотеку requests.
Документация по API Opensky: https://openskynetwork.github.io/opensky-api/rest.html
Документация по API Nominatim: https://nominatim.org/release-docs/latest/api/Overview/
* Выберите не менее 4 стран, за самолетами которых вы будете следить в воздушном пространстве.
* Спроектируйте таблицы в БД PostgreSQL для хранения полученных данных о странах и самолетах. Для работы с БД используйте библиотеку 
psycopg2.
* Реализуйте код, который заполняет таблицы, созданные в БД PostgreSQL.
* Создайте класс DBManager для работы с данными в БД. 
* Класс DBManager. Создайте класс DBManager, который будет подключаться к БД PostgreSQL и иметь следующие методы:

* get_countries_and_aeroplanes_count() — получает список всех стран и количество самолетов в их воздушных пространствах.
* get_all_aeroplanes() — получает список всех воздушных судов.
* get_avg_speed() — получает среднюю скорость по самолетам.
* get_aeroplanes_with_higher_speed() — получает список всех самолетов, у которых скорость выше средней.
* get_aeroplanes_with_keyword() — получает список всех самолетов, в позывном которых содержатся переданные в метод символы.
* Пример 'ACA' — самолеты авиакомпании Air Canada.

* Класс DBManager должен использовать библиотеку psycopg2 для работы с БД.
